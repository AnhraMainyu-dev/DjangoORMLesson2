# Сайт доставки еды Star Burger

Это сайт сети ресторанов Star Burger. Здесь можно заказать превосходные бургеры с доставкой на дом.

![скриншот сайта](https://dvmn.org/filer/canonical/1594651635/686/)


Сеть Star Burger объединяет несколько ресторанов, действующих под единой франшизой. У всех ресторанов одинаковое меню и одинаковые цены. Просто выберите блюдо из меню на сайте и укажите место доставки. Мы сами найдём ближайший к вам ресторан, всё приготовим и привезём.

На сайте есть три независимых интерфейса. Первый - это публичная часть, где можно выбрать блюда из меню, и быстро оформить заказ без регистрации и SMS.

Второй интерфейс предназначен для менеджера. Здесь происходит обработка заказов. Менеджер видит поступившие новые заказы и первым делом созванивается с клиентом, чтобы подтвердить заказ. После оператор выбирает ближайший ресторан и передаёт туда заказ на исполнение. Там всё приготовят и сами доставят еду клиенту.

Третий интерфейс - это админка. Преимущественно им пользуются программисты при разработке сайта. Также сюда заходит менеджер, чтобы обновить меню ресторанов Star Burger.

Пробная версия сайта доступна по адресу https://vps.helelfree.site/

## Как запустить dev-версию сайта

Для запуска сайта нужен установленный Docker Desktop
Создайте файл `.env` в корне проекта и заполните необходимые переменные окружения:

- `DEBUG` - дебаг-режим. Поставьте `True`.
- `SECRET_KEY` - секретный ключ проекта. Он отвечает за шифрование на сайте.
- `ALLOWED_HOSTS` - [см. документацию Django](https://docs.djangoproject.com/en/5.2/ref/settings/#allowed-hosts)
- `YANDEX_API_KEY` - API-ключ к сервису Яндекс-геокодера. Необходим для рассчёта расстояния от ресторана к адресу заказа. Получить можно в [кабинете разработчика Яндека](developer.tech.yandex.ru),
требуется регистрация.
- `POSTGRES_DB` - имя базы данных, выбирается произвольно.
- `POSTGRES_USER` - логин для входа в базу данных.
- `POSTGRES_PASSWORD` - пароль для входа в базу данных.

Запустите проект и примените миграции:

```sh
docker compose up -d
docker compose exec backend python manage.py migrate
```

Docker Compose установит зависимости, соберёт бэк, фронт и поднимет базу данных самостоятельно.

Откройте сайт в браузере:
http://127.0.0.1:8000/

## Как запустить prod-версию сайта

Для запуска production-версии используется отдельная конфигурация Docker Compose - `docker-compose.prod.yaml`.

Создайте файл `.env` в корне проекта и укажите необходимые переменные окружения:

- `DEBUG` - дебаг-режим. Поставьте `False`.
- `SECRET_KEY` - секретный ключ проекта. Он отвечает за шифрование на сайте. Например, им зашифрованы все пароли на вашем сайте.
- `ALLOWED_HOSTS` - [см. документацию Django](https://docs.djangoproject.com/en/5.2/ref/settings/#allowed-hosts)
- `YANDEX_API_KEY` - API-ключ к сервису Яндекс-геокодера. Необходим для рассчёта расстояния от ресторана к адресу заказа. Получить можно в [кабинете разработчика Яндека](developer.tech.yandex.ru),
требуется регистрация.
- `POSTGRES_DB` - имя базы данных, выбирается произвольно.
- `POSTGRES_USER` - логин для входа в базу данных.
- `POSTGRES_PASSWORD` - пароль для входа в базу данных.
- `ROLLBAR_ACCESS_TOKEN` - ваш токен из сервиса [Rollbar](https://rollbar.com/) для логгирования ошибок сайта.
- `ROLLBAR_ENVIRONMENT` - название окружения для Rollbar. Укажите production.

Адрес базы данных `DATABASE_URL` формируется в Docker Compose автоматически.

Запуск production-версии:

```sh
docker compose -f docker-compose.prod.yaml up -d --build
docker compose -f docker-compose.prod.yaml exec backend python manage.py migrate
docker compose -f docker-compose.prod.yaml exec backend python manage.py collectstatic --noinput
```

## Как обновить prod-версию сайта

В корне репозитория расположен скрипт `deploy_starburger.sh`.

После изменения репозитория выполните на сервере из корня проекта:

```sh
./deploy_starburger.sh
```
